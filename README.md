
# 🎨 Animação Background

Projeto de animação de fundo desenvolvido com **HTML5 e CSS3** como parte de uma atividade prática do curso PROA.

O projeto tem como objetivo explorar conceitos de animações CSS, transformações geométricas e movimentação de elementos, criando um fundo dinâmico com formas que se movimentam continuamente pela tela.

## Funcionalidades e características

- Fundo com gradiente de cores em tons de laranja e amarelo.
- Animações contínuas de formas geométricas utilizando CSS.
- Movimentação de elementos em diferentes direções.
- Efeitos de rotação, crescimento e alteração de opacidade.
- Animações com diferentes tempos de início utilizando `animation-delay`.
- Título centralizado sobre o fundo animado.

## Tecnologias utilizadas

- **HTML5:** estruturação e organização dos elementos da página.
- **CSS3:** estilização, criação de gradientes, transformações e animações.

## Aprendizados

Durante o desenvolvimento, foram praticados conceitos como:

- Estruturação de elementos utilizando HTML.
- Criação de animações com `@keyframes` e `animation`.
- Utilização de transformações com `scale()` e `rotate()`.
- Manipulação de opacidade e posicionamento de elementos.
- Aplicação de gradientes utilizando `linear-gradient()`.
- Controle de animações com `animation-delay` e `infinite`.
- Utilização de `nth-child()` para personalizar elementos individualmente.
